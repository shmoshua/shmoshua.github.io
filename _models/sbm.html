--- layout: post title: "Stochastic Block Model (SBM)" summary: "Community detection in a random graph with a planted partition." ---

Setup

Two balanced communities: assign each vertex $i \in [n]$ a label $\sigma_i \in \{\pm 1\}$ uniformly at random. Connect $i$ and $j$ independently with probability $a/n$ if $\sigma_i = \sigma_j$ and $b/n$ otherwise. Goal: recover $\sigma$ from the graph, up to a global sign.

Weak recovery means outputting $\hat\sigma$ with overlap $\big|\tfrac1n \sum_i \hat\sigma_i \sigma_i\big| \ge \delta$ for some $\delta > 0$, with probability $1 - o(1)$.

Results

Kesten–Stigum threshold

Weak recovery is possible if and only if $(a-b)^2 > 2(a+b)$.

Equivalently, with $a = d(1+\varepsilon)$, $b = d(1-\varepsilon)$ and $\lambda = \varepsilon\sqrt d$: weak recovery is possible if and only if $\lambda > 1$.

Mossel–Neeman–Sly (impossibility below); Massoulié and Mossel–Neeman–Sly (algorithms above).
